# Audio Review

A standardized listening-test platform for headphones and other audio equipment.

## Help Us Build a Standardized Audio Testing Platform

We're building a standardized listening test for headphones and other audio equipment.

The idea is simple: everyone gets the same audio tests, the same instructions, and the same evaluation process. Instead of relying on random listening impressions, we want to see what happens when many people test their equipment using a consistent methodology.

And right now, we need testers.

Run the full test with whatever headphones you have. Expensive, cheap, wired, wireless — it doesn't matter. We're interested in the results, but we're also **testing the test itself**.

Did the questions make sense? Were any tests confusing? Did something not work? Did your results seem accurate to what you actually heard?

The more people who test the same equipment, the more useful the data becomes.

**This is an early public beta. Dive in, test your headphones, break things, and tell us what happened.**

## What We're Trying to Learn

The goal at this stage is repeatability. By giving different listeners the same source material, instructions, and evaluation process, we can study how consistently people evaluate the same equipment.

This is a structured listening test, not a laboratory measurement system. Results reflect what listeners hear through their own equipment and hearing, and should not be interpreted as calibrated acoustic measurements.

## Getting Started

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser and run the complete test.

## Feedback

If something is confusing, inconsistent, broken, or just feels wrong, please report it. Feedback about the testing methodology is just as valuable as feedback about the software itself.
